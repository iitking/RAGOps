FastAPI handles asynchronous dependency injection by utilizing Python's async def syntax combined with yield statements. The execution follows a two-phase lifecycle:

1. Setup Phase: Code executed prior to the yield expression establishes the resource (such as an asynchronous database session) directly on the asyncio event loop [Doc 05: Sec 3].
2. Teardown & Cleanup: Following the completion of the route handler, execution resumes immediately after yield, ensuring cleanup (e.g. session.close()) always runs even if unhandled exceptions were raised [Doc 09: Sec 2].
