FastAPI handles asynchronous dependency injection using Python's async def syntax combined with yield expressions. The lifecycle is executed in two predictable phases:

  • Resource Setup (Before Yield): The code before yield runs before the route handler. It creates resources (like an asynchronous database session) directly on Starlette's asyncio event loop [Doc 05: Injection].
  • Automatic Teardown (After Yield): Once the response is sent back to the client, execution resumes after yield to safely close connections (e.g. session.close()), even if an unhandled exception occurred [Doc 09: Async Sessions].
